# Word 文档在线预览与格式调整工具（本地桌面版）

一个基于 Python 的本地桌面工具：打开 `.docx` 文档按段落双页预览，自动识别标题层级，
支持批量选取与统一格式调整、目录/页码/参考文献处理、文本清理与撤销重做。

后续更新将在 gitcode 上同步更新。如存在问题请联系作者：Enrich_service

---

## 一、工具用途

- 打开 `.docx` 文档并按段落双页预览（A4 页面模拟）。
- 自动识别段落层级（大标题、一级、二级、三级、四级、正文）。
- 支持按分类或标题管辖范围批量选取段落。
- 对选中段落统一调整格式（字号、字体、行间距、加粗、斜体、下划线、对齐、首行缩进）。
- 支持目录生成/更新、页码分节、参考文献 GB/T 7714 格式化与校验、文本清理、撤销重做。
- 底部状态栏实时显示操作反馈、选中数量与可撤销/重做次数。

## 二、环境要求

- Python 3.10+
- Windows / macOS / Linux（推荐桌面图形环境）
- 依赖（见 `requirements.txt`）：
  - python-docx>=1.1.0
  - customtkinter>=5.2.0
  - Pillow>=10.0.0

## 三、安装与启动

在项目根目录执行：

```bash
pip install -r requirements.txt
python run.py
```

Windows 下也可双击 `start.bat`（会自动检测依赖，缺失时先安装再启动）。


## 五、界面说明

- **顶部栏**：打开文档、保存、另存为、当前文件名、快捷键提示。
- **左侧区域**：双页 A4 预览、段落页码与级别标注（如 `P1 [1级]`）、
  选取/全选/取消/分类选取按钮、翻页器。
- **右侧工具栏**：字体字号、行间距、页边距（含“每页X行/每行Y字”网格信息）、
  样式 B/I/U、对齐、页码分节、目录、参考文献、文本清理等。
- **底部状态栏**：操作反馈（如“已应用字号 12pt”）、选中段数、可撤销/重做次数。

## 六、推荐使用流程

1. 打开文档。
2. 在预览区选择段落（单击单选，Ctrl+点击多选，右键局部取消）。
3. 使用分类按钮或“选取/批量选择”建立选区。
4. 在右侧应用格式（字号、字体、行距、对齐等）。
5. 处理页码与目录（一键分节并设置页码 → 自动生成目录 → 更新目录 → 一致性校验）。
6. 处理参考文献（选择制式 → 格式化 → 悬挂缩进 → 全面校验 → 一键修改）。
7. 保存或另存为。

## 七、常用功能提示

- 字号支持下拉选择，也支持 `-` / `+` 步进。
- 行间距：单倍(1.0) / 1.5倍 / 2倍 / 固定18pt（固定值为精确 18pt）。
- **打开文档不会改写任何行距**：单倍、双倍、固定值等用户原有格式一律保留，
  仅在使用工具主动应用行距时才会修改。
- 查找与替代位于选取栏，支持查找下一处/上一处、替换当前、全部替换。
- 文本清理按钮：删除#、删除*、删除占位.、保留数字间-、删除空段落。

## 八、页码与目录规则

- 封面不编页码。
- 前置部分（含目录）使用罗马页码连续编码。
- 正文及后置部分使用阿拉伯页码连续编码，正文第一页为 1。
- 目录列出正文及后续部分标题，重复更新目录不会产生累积空白页。
- 目录-页码一致性校验基于正文估算页，内置 ±1 页容差以降低分页临界误报。

## 九、参考文献规则

- 支持顺序编码制、著者-出版年制。
- 支持悬挂缩进一键设置、文献全面校验与一键修改。
- 识别范围默认在“参考文献”与“致谢”之间（按标题精确识别，避免误命中目录行）。
- 类型标识（[J]/[M]/[D]/[C] 等）按文献内容推断；原文已带标识则保留，
  **无法判断时不添加任何标识**（不会默认补 [J]）。

## 十一、段落分类规则

程序优先按编号规则识别层级，其次结合样式特征辅助判断：

- 一级：第 1 章 / 第 一 章 / 1绪论（编号+标题词）
- 二级：1.1
- 三级：1.1.1
- 四级：（1）
- 大标题：文档前部满足标题特征的总标题
- 正文：其余段落

选取按钮的范围规则：光标在标题时，取该标题到下一同级或更高层标题之前的区间；
光标在正文时，向上追溯最近标题再按同样规则取范围；全文无标题时只返回当前段落。

## 十三、常见问题

1. **按钮没有效果**：请先打开文档；格式修改或局部清理前，请先选中至少一个段落。
2. **标题识别为正文**：编号规则优先；可通过分类按钮手动选中后继续操作，不影响保存。
3. **控制台乱码**：可能是终端编码显示问题，不影响 docx 读写结果。
4. **目录/页码在 Word 中未刷新**：在 WPS/Word 中执行一次“更新域/更新目录（F9）”。
