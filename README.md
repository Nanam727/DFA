一、工具用途

打开 .docx 文档并按段落预览。

自动识别段落层级（大标题、一级、二级、三级、四级、正文）。

支持按分类或标题管辖范围批量选取段落。

对选中段落进行统一格式调整（字号、字体、行间距、加粗、斜体、下划线、对齐等）。

支持目录、页码、参考文献、文本清理、撤销重做、页面刷新等功能。



二、环境要求

Python 3.10+

Windows / macOS / Linux（推荐桌面图形环境）

依赖：

python-docx>=1.1.0

customtkinter>=5.2.0

Pillow>=10.0.0



三、安装与启动

在项目根目录执行：

pip install -r requirements.txt

python run.py



四、一键修复（fix.bat）

当出现“无法启动、缺少依赖、运行报错”时，先执行 fix.bat。

执行方式：

1\) 双击项目根目录中的 fix.bat

2\) 脚本会自动执行：

检测 Python（python 或 py -3）

升级 pip

安装 requirements.txt 依赖

语法检查 run.py、src/main.py、src/docx\_handler.py、src/align\_icons.py

3\) 出现 \[DONE] Repair completed successfully. 即表示完成

4\) 之后运行 start.bat 或 python run.py



说明：

fix.bat 不会删除文档，也不会覆盖业务逻辑源码。



五、项目结构

start.bat

requirements.txt

src/

&nbsp; main.py

&nbsp; docx\_handler.py

&nbsp; align\_icons.py

1\) 打开文档

2\) 在预览区选择段落（支持 Ctrl+点击 多选）

3\) 使用分类按钮或“选取/批量选择”建立选区

八、常用功能提示

字号支持下拉选择，也支持 + / - 步进。

查找与替代功能位于选取栏，可进行查找下一处、替换当前、全部替换。

文本清理：

删除#

删除\*

删除占位.

保留数字间-

删除空段落



九、页码与目录规则

封面不编页码。

前置部分（含目录）使用罗马页码连续编码。

正文及后置部分使用阿拉伯页码连续编码，正文第一页为 1。

目录会列出正文及后续部分标题，并与正文页码体系协调。

目录-页码一致性校验基于正文估算页，内置 ±1 页容差以降低分页临界误报。



十、参考文献规则

支持顺序编码制、著者-出版年制。

支持悬挂缩进一键设置。

支持文献全面校验和一键修改。

默认识别范围在“参考文献”与“致谢”之间（按标题精确识别，避免误命中目录行）。



十一、快捷键

Ctrl + S：保存

Ctrl + Z：撤销

Ctrl + Y：重做

Ctrl + X：刷新页面



十二、常见问题

1\) 按钮无效：

请确认已打开文档，并已选中段落（针对局部格式功能）。

2\) 标题识别偏差：

可通过分类按钮手动选中后继续操作，不影响保存。

3\) 控制台乱码：

可能是终端编码显示问题，不影响 docx 读写结果。

Word 文档在线预览与格式调整工具（本地桌面版）



一个基于 Python 的本地桌面工具，用于：

打开 .docx 文档并按段落预览

自动识别段落层级（大标题、一级、二级、三级、四级、正文）

按分类或标题管辖范围批量选取段落

对选中段落统一进行格式调整（字号、行间距、加粗、对齐）

对文本执行清理操作（删 # / \* / - 等）

支持清理操作撤销（Ctrl+Z）

保存或另存为新的 .docx

1\. 环境要求



Python 3.10+

Windows / macOS / Linux（推荐有桌面图形环境）

依赖：

python-docx>=1.1.0

customtkinter>=5.2.0

5\. 使用说明（推荐流程）



5.1 快速上手（3 分钟）

1\. 点击 打开文档，选择一个 .docx 文件。

2\. 在左侧预览区点击任意段落建立选区（可多选）。

3\. 在右侧工具栏选择操作（字号、字体、行距、对齐、目录、页码、参考文献等）。

4\. 点击 保存（覆盖）或 另存为（新文件）。



5.2 选择段落的几种方式

鼠标点击：单选

Ctrl + 点击：多选切换

全选：选中所有段落

取消 或 Ctrl + D：清空当前选区

分类按钮：大标题/一级/二级/三级/四级/正文 一键按级别选中

批量选择：弹窗勾选多个级别后一次性选中

选取：按“当前锚点标题管辖范围”选中整段落区间



5.3 字号与字体调整

在 字号 区可直接下拉选择，也可以点击 - / + 逐级调整字号。

\- / + 会按常用字号阶梯步进，并立即应用到当前选中段落。

字体下拉可直接切换选中段落字体。



5.4 常用格式操作

行间距：单倍 / 1.5 倍 / 2 倍 / 固定 18pt

样式：B（加粗）、I（斜体）、U（下划线）

对齐：左对齐 / 居中 / 右对齐 / 两端对齐

全文首行缩进 2 字符：用于快速统一正文段落缩进



5.5 页码、分节、目录（论文场景）

推荐顺序：

1\. 先点击 一键分节并设置页码

2\. 再点击 自动生成目录

3\. 文档改动后，使用 更新目录（仅页码） 或 更新目录（整个目录）

4\. 最后用 目录-页码一致性校验 检查结果



说明：

封面默认不编页码

前置部分（含目录）使用罗马页码

正文及后置部分使用阿拉伯页码，并从正文第一页开始计 1



5.6 参考文献处理建议

1\. 先选择模式：顺序编码制 或 著者-出版年制

2\. 点击 格式化参考文献

3\. 点击 悬挂缩进一键设置

4\. 点击 文献全面校验

5\. 如有问题，点击 一键修改（校验后使用）



参考文献识别范围：默认在“参考文献”与“致谢”之间（按标题精确识别，避免误识别目录中的同名条目）。



5.7 清理按钮说明

删除#：删除选中段落中的 #

删除\*：删除选中段落中的 \*

删除占位.：仅删除“单独占一行的 .”

保留数字间-：仅保留 数字-数字 之间的连字符

删除空段落：全局删除空白段落



5.8 撤销/重做

Ctrl + Z：撤销上一步操作

Ctrl + Y：重做上一步操作

Ctrl + X：刷新页面

适用于主要格式操作与清理操作。



====================================



6\. 段落分类规则



程序优先按编号规则识别层级，其次结合样式特征辅助判断：

一级：一、二、三……

二级：（一）（二）（三）……

三级：1. 2. 3. ……

四级：（1）（2）（3）……

大标题：文档前部满足标题特征的唯一总标题（扩展级别）

正文：其余段落



选取按钮的范围规则：

光标在标题：从该标题到下一同级或更高层标题之前

光标在正文：向上追溯最近标题，再按同样规则取范围

全文无标题：只返回当前段落

8\. 文本清理与撤销/重做



清理范围：

删除空段落：全局处理（整个文档）

其它清理按钮：仅作用于当前选中段落



保留数字间-：

仅保留 数字-数字 之间的连字符，例如：

2023-2024 保留

A-B 删除连字符

测试-文本 删除连字符



撤销：

快捷键 Ctrl + Z

撤销上一步操作（主要格式与清理）



重做：

快捷键 Ctrl + Y

重做最近一次已撤销操作

保存：覆盖当前文件

另存为：保存到新路径

10\. 常见问题



1\) 点击按钮没有效果

请先确认已打开文档

格式修改或局部清理前，请先选中至少一个段落



2\) 为什么某些标题识别为正文

编号规则优先；若标题未按常见编号格式，依赖样式辅助判断

可通过手动选择段落继续处理，不影响格式修改和保存



3\) 乱码问题

控制台日志可能受终端编码影响显示异常

不影响 docx 本体读写与界面操作
